*DESCRIPTION*: Task-1: Data Preprocessing, Transformation, and Loading (ETL Pipeline)
In this task, I developed an automated ETL pipeline using Python, Pandas, and Scikit-learn to preprocess raw data for machine learning applications. The dataset was analyzed to identify missing values and data inconsistencies. Separate preprocessing pipelines were created for numerical and categorical features using imputation, scaling, and encoding techniques. These pipelines were integrated using Scikit-learn’s Pipeline and ColumnTransformer for automation and reusability. The transformed data was then saved in a structured format for further analysis. This task demonstrates efficient and scalable data preprocessing following industry-standard practices.
